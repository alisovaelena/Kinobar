# Кинобар — электронное меню на телевизорах

Один компьютер, к нему подключены телевизоры (по умолчанию 5). На каждом телевизоре открыта
своя страница меню. Менеджер со своего браузера (компьютер, телефон) меняет цены в
«менеджерской» и нажимает **«Сохранить и показать на ТВ»** — все экраны обновляются за секунду,
без перезагрузки. Изменившаяся цена коротко подсвечивается на экране.

## Что внутри

| Адрес | Что это |
|---|---|
| `http://<компьютер>:3000/screen/1` … `/screen/5` | страницы для телевизоров (тёмная тема, текст сам подгоняется под размер экрана) |
| `http://<компьютер>:3000/admin` | менеджерская: цены, названия, объёмы, «старая цена», «в наличии», «хит», скрыть позицию, разделы, экраны |
| `http://<компьютер>:3000/` | список всех ссылок |

* Работает без интернета, только в локальной сети.
* Нужен только **Node.js 18+**, больше ничего ставить не надо.
* Меню хранится в `data/menu.json`, перед каждым сохранением делается резервная копия в `data/backups/` (последние 50).
* Если сервер на время пропал, телевизоры продолжают показывать последнее меню (в углу загорается красная точка) и сами переподключаются.
* В менеджерской есть «Скачать резервную копию меню» и «Загрузить меню из файла».

## Установка на компьютер с телевизорами (Windows)

1. Установите Node.js LTS с https://nodejs.org.
2. Скопируйте папку проекта, например в `C:\Kinobar`.
3. Откройте `scripts\start-server.bat` в Блокноте и поменяйте пароль в строке `set ADMIN_PASSWORD=kinobar`.
4. Запустите `scripts\start-server.bat` — сервер работает, пока открыто это окно (и сам перезапускается при сбое).
5. Запустите `scripts\start-screens.bat` — на каждом мониторе откроется Chrome на весь экран
   с нужной страницей (монитор 1 → `/screen/1` и т.д., слева направо по настройкам экранов Windows).
   Если порядок не совпал — поменяйте местами мониторы в «Параметры → Дисплей» или
   поменяйте заголовки/позиции экранов в менеджерской.
   Выйти из полноэкранного окна: `Alt+F4`.

**Автозапуск при включении компьютера:** нажмите `Win+R`, введите `shell:startup` и положите туда
ярлыки на `start-server.bat` и `start-screens.bat`. Также в настройках Windows отключите сон и
заставку для экранов.

**Доступ менеджера с другого компьютера / телефона:** узнайте IP компьютера (`ipconfig`, строка IPv4,
например `192.168.1.50`) и откройте `http://192.168.1.50:3000/admin`. Логин — любой, пароль — тот,
что указан в `start-server.bat`. При первом запуске Windows спросит разрешение брандмауэра —
разрешите доступ для частных сетей.

## Работа в менеджерской

* Вкладки «ТВ 1 … ТВ 5» — содержимое каждого телевизора, «⚙ Настройки» — валюта, добавить/удалить экран, резервные копии.
* Изменённые, но ещё не сохранённые цены подсвечены оранжевым. Сохранить — кнопка вверху или `Ctrl+S`.
* «Старая цена» — показывается зачёркнутой рядом с новой (акции).
* Снятая галочка «Есть» — позиция показывается бледной с надписью «закончился»; «Скрыть» — убирает её с экрана совсем.

## Для разработчика

```bash
npm start     # сервер на http://localhost:3000 (PORT, ADMIN_PASSWORD, DATA_DIR — переменные окружения)
npm test      # автотесты API
```

Стартовое меню — `data/menu.default.json` (используется, пока нет `data/menu.json`).
